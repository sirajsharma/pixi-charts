Verification checklist

  • Visual — same font, same axis style, consistent colors across charts where applicable; no obviously mismatched typographic scale.
  • Hover — tooltip works on every chart, shows correctly formatted values and the right field names.
  • Animation — each chart's enter animation runs once on initial load; hard-reload to re-observe.
  • Resize — drag the browser window; every chart resizes cleanly with no clipping, overflow, or axis misalignment.
  • Console — no errors, no unexpected warnings (deliberate soft-warns about data omissions are acceptable).
  • Memory — hot-reload several times; DevTools Memory tab should not show steady growth between reloads.
