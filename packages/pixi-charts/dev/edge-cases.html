pixi-charts — rendering edge cases

Three adversarial cases that the original happy-path harness missed: dark theme on a dark background, long category labels on a horizontal bar chart, and corner-hover tooltip positioning on a small chart.

1. Dark theme

Axis ticks, gridlines, axis line, and legend text should all be readable on the dark page background.

2. Long band-axis labels (horizontal bar)

Left margin must size to fit the widest category label, capped at 35% of chart width. Labels that exceed the cap should be ellipsis-truncated.

3. Tooltip near container edges

Hover near each of the four corners of this small chart. The tooltip should flip / clamp to stay fully inside the dashed boundary — never escape.
