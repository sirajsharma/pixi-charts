# pixi-charts

> A WebGL-rendered TypeScript charting library built on [PixiJS](https://pixijs.com/) and D3 submodules.

**Status:** alpha — under active development. API is not yet stable.

```sh
pnpm add pixi-charts pixi.js
```

`pixi.js` (^8) is a **peer dependency** — install it alongside `pixi-charts`.

See the [repo root](https://github.com/TODO/pixi-charts) for the full README, contributing guide, and roadmap.
