This page is under construction. The TypeDoc-generated API reference will surface here once it's wired into the Starlight nav; the underlying types are stable today and exported from the package root.

For now:

- `render(spec, container) → Promise<Chart>` — primary entry point.
- `ChartSpec` — the declarative shape; see the [Getting Started page](/getting-started/) for the model.
- Chart classes (`LineChart`, `AreaChart`, `BarChart`, `ScatterChart`, `HeatmapChart`, `PieChart`) — exported for imperative use cases that need direct control.
